*DESCRIPTION*: This project implements a Real-Time Chat Server using Node.js and Socket.IO. The application enables multiple users to communicate in real-time by joining chat rooms, sending and receiving messages instantly. Users can join or leave chat rooms, and messages are broadcast only to members of the respective room. The system is designed to handle multiple concurrent users efficiently, making it scalable and extensible for features like private messaging, typing indicators, and message history.

*TECH STACK* 

Backend: Node.js

Real-time communication: Socket.IO

HTTP Server: Express.js

Database: MongoDB
